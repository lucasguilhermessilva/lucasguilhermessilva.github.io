Agentes de IA no WhatsApp, como plataforma

Fast IA. Sou o CTO.

O problema
Clínicas e empresas perdem clientes quando ninguém responde no WhatsApp, e agentes feitos um a um são difíceis de manter certos depois que entram no ar.
O que eu construí
Uma plataforma multiempresa em que cada empresa tem os seus agentes de IA. Um orquestrador lê a conversa e escolhe a intenção, e um executor faz o trabalho: responde, agenda um horário no sistema da própria clínica ou passa a conversa para uma pessoa. Lead que some recebe um follow-up automático dentro de uma janela de horário permitida. As mensagens entram pela API oficial da Meta e pela Z-API. Os dados ficam em Postgres com segurança por linha (RLS) e a lógica roda em Edge Functions.
O que mostra que funciona
Agentes rodando em produção para clínicas e empresas. Nomes de clientes, telas e números ficam privados.
Tecnologias
Supabase (Postgres, Edge Functions, RLS), TypeScript, Deno, n8n, Meta Cloud API, Z-API, OpenAI, Claude

Sem Play

Produto meu. Em desenvolvimento.

O problema
Os áudios se acumulam no WhatsApp, nem sempre dá para ouvir, e dar play avisa quem mandou que o áudio foi ouvido.
O que eu construí
Uma extensão do Chrome (Manifest V3) que transforma os áudios do WhatsApp Web em texto dentro da conversa, sem tocar o áudio. Ela separa data, horário, endereço, valor e telefone para copiar. Um servidor em Supabase cuida das contas, dos limites de uso e da transcrição, e os pagamentos por Pix e cartão rodam em modo de teste.
O que mostra que funciona
A extensão, o servidor e o fluxo de pagamento têm testes automatizados. Ainda não está na loja do Chrome.
Tecnologias
JavaScript, extensão do Chrome (Manifest V3), Supabase (Postgres, Edge Functions), transcrição de voz pelo OpenRouter, pagamentos Asaas, Playwright

Automação de tradução e diagramação de mangá e manhwa

Meu projeto de engenharia. Em uso.

O problema
Diagramar um capítulo é colocar o texto traduzido dentro de cada balão, página por página, à mão no Photoshop.
O que eu construí
Um app de desktop e um motor em Python. Ele lê os balões de cada página, encaixa o texto traduzido na fonte e no tamanho certos e exporta as páginas em arquivos editáveis, prontas para revisão. Controla o Photoshop por COM e usa um modelo de IA para casar cada frase com o seu balão.
O que mostra que funciona
Um portão de qualidade medido compara cada resultado com capítulos feitos à mão antes de uma versão sair.
Tecnologias
Python, PySide6, automação do Photoshop (COM), OCR, OpenRouter

Automação de canais do YouTube

Projeto meu. Rodando desde outubro de 2026.

O problema
Manter um canal alimentado exige fazer, agendar e conferir um fluxo constante de vídeos. À mão, isso não escala.
O que eu construí
Um pipeline em Python que gera conteúdo de passatempos, quiz e história, renderiza Shorts verticais e vídeos longos com ffmpeg, coloca narração e legendas e agenda os envios pela API do YouTube. Em volta ficam os sites dos canais, um funil de vendas na Kiwify e um painel local pequeno em SQLite.
O que mostra que funciona
Rodando desde outubro de 2026: cerca de 22 mil linhas de Python em 82 arquivos, e cada envio é lido de volta pela API do YouTube para confirmar.
Tecnologias
Python, ffmpeg, APIs de Dados e de Analytics do YouTube, SQLite, faster-whisper, ElevenLabs, sites em Next.js

Motor de cálculo de expurgos inflacionários

Trabalho para cliente. No ar.

O problema
Um escritório de advocacia previdenciária precisava ler extratos de poupança de décadas atrás e aplicar à mão as regras de cada plano econômico, depois copiar os saldos para uma calculadora.
O que eu construí
Uma ferramenta web em que o estagiário envia o extrato e recebe banco, conta, data-base e saldo, os índices dos planos Bresser, Verão e Collor aplicados, a faixa de desconto pelas regras do acordo e um relatório em texto para copiar. Roda numa função serverless e mostra o aviso de conferir todos os números.
O que mostra que funciona

JavaScript, Node.js na Vercel, um modelo de visão de IA

Leitor de documentos com OCR e IA

Trabalho para cliente.

O problema
Os processos do mesmo escritório passam de 300 páginas, e as poucas páginas que importam são extratos escaneados no meio de petições.
O que eu construí
Um app em Python que divide o PDF em páginas, descarta as páginas só de texto com um filtro local, lê as páginas escaneadas com OCR e um modelo de visão, guarda só os extratos do cliente indicado e devolve os campos como dados estruturados. Tenta de novo sozinho quando o serviço de IA está ocupado.
O que mostra que funciona
Página só de texto nunca chega à IA, o que reduz o número de chamadas pagas num arquivo longo. O app não tem página pública.
Tecnologias
Python, Streamlit, PyMuPDF, asyncio, um modelo de visão de IA

API de carteira digital

Projeto de referência. Feito para mostrar fundamentos de backend.

O problema
Numa API de pagamentos, uma nova tentativa do cliente ou duas requisições ao mesmo tempo nunca podem mover o dinheiro duas vezes nem deixar os saldos fora de sincronia.
O que eu construí
Uma API REST de carteira digital em Go. Cada transferência roda numa única transação SERIALIZABLE do Postgres, com os bloqueios de linha tomados sempre na mesma ordem, para que duas transferências entre as mesmas carteiras não travem uma à outra. Uma Idempotency-Key repetida devolve a resposta guardada no Redis em vez de mover o dinheiro de novo. Tem também autenticação JWT, um pool de workers e ambiente com Docker Compose.
O que mostra que funciona
Testes unitários cobrem as camadas de serviço, worker e autenticação.
Tecnologias
Go, Fiber, PostgreSQL, Redis, JWT, Docker
